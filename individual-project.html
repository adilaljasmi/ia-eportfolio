Individual Project (Unit 11)

ScholarPlan built, tested and demonstrated as a cooperating multi-agent system.

ScholarPlan: implementation and presentation (Unit 11, individual, 40%)

In Unit 11 I implemented the team's design on my own as a working multi-agent system. A research goal in plain English is decomposed by the Planner, which uses a ReAct loop. The Retriever queries arXiv, OpenAlex and Crossref. The Processor deduplicates, ranks and extracts atomic claims. A Critic from a different model family checks every claim against its source. The Archivist stores a cited report, a BibTeX file, a vector index and a full reasoning trace. All agents coordinate only through the SQLite blackboard.

Responding to the Unit 6 tutor feedback

  • Structural view: I added a UML class diagram drawn from the actual code.
  • Measurable targets: I set them before testing (table above), with deduplication and relevance thresholds of 0.92 and 0.30 cosine similarity defined as named constants.
  • Fallback rules: I enforced a hard cap of three re-plans per subtask in code. On the fourth failure the subtask is marked “unresolvable” without calling the LLM.
